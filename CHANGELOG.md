# Changelog

## v4.4 — 2026-10-17

First public release.

### Changed
* **No site data ships in the build.** The 203 real articles that were inlined
  in `index.html` are gone. The trainer now boots on 18 fictional demo
  articles.
* **Price lists are loaded in the browser.** The Price list tab takes a CSV or
  JSON file, stores it in `localStorage` on that device, and uses it as the
  article database. Export CSV/JSON gives a template or a copy back. See
  [docs/plu-format.md](docs/plu-format.md).
* **Nothing site-specific is hard-coded.** The site name, the level 9 customer
  macro label and the customer it filters on are set in Settings and stored in
  the browser. Drills and screen text no longer name customers or specific
  PLUs; the line boots on whichever article the loaded list starts with.
* `index.html` is a proper document now — doctype, `<meta charset>`, viewport,
  icons, manifest and social card. Opened from disk it no longer mangles
  non-ASCII characters.

### Added
* Icons, web app manifest and OG card, generated by `tools/make_icons.py`.
* `tools/pricelist_to_plu.py` — Retail Product Information Sheet `.xlsm` to
  PLU JSON/CSV, dropping any email address it finds.
* `src/build.py` rebuilds `index.html` from `src/` and `data/`; the Pages
  workflow fails the deploy if the committed file is stale or if a spreadsheet
  or `prices.json` has been committed.
* README, NOTICE, licence, `.gitignore` tuned to keep real data out.
